## 三网回程路由实测：电信、联通、移动各走什么线

结论先说：电信双向 CN2 GIA，移动双向 CMIN2，联通去程走普通 4837 骨干、回程被强制绕行 CMIN2。

具体拆开看：

- **电信**：去程 CN2 GIA 直连洛杉矶，回程也走 CN2 直接回国，全程精品网，是这个套餐最稳的一条线。
- **联通**：去程走 AS4837 骨干网到洛杉矶，回程从洛杉矶强制走 CMIN2（AS58807）直回上海。换句话说，联通用户只有回程享受优化线路。
- **移动**：去程 CMI 直连，回程 CMIN2 从洛杉矶直回上海。

很多宣传材料把这套配置笼统写成“三网优化”，但联通去程走 4837 这个细节很少有人讲清楚——它直接影响联通用户上传文件、视频通话这类双向流量的体验。主力线路是电信或移动的话不用纠结；联通用户建议利用退款期实测一下再做去留。

延迟方面，同一机房同线路配置下的第三方实测：上海移动约 126ms，上海电信 5G 约 133ms，成都移动约 160ms，上海联通 5G 约 174ms，广州联通约 195ms。都是洛杉矶机房的正常水平，联通偏高一些和去程线路有关。

## 实际性能：CPU、磁盘和晚高峰带宽

硬件性能中规中矩，网络才是这个套餐的长板；晚高峰有波动，但整体扛得住。

CPU 方面，BiggerBox Pro 是单核 EPYC 9004，实测主频 2794MHz。同机房同代处理器的 MEGABOX-PRO（2 核）跑分可以当参考：SysBench 单核 1561–1645 分、多核 3126–3297 分，Geekbench 5 单核 813、多核 1464。AES-NI 指令集开启，跑加密相关任务没问题；但已有实测显示 AMD-V/VM-x 处于关闭状态，想在 VPS 里再套虚拟机的需求直接排除。

磁盘成绩分两个来源：BiggerBox Pro 的 FIO 测试约 993MB/s；MEGABOX-PRO 的 4K 随机读写约 149MB/s（3.7 万 IOPS 上下），1M 大块读写 1.6–1.8GB/s。不同测评的测试时间和工具不一样，数字有出入很正常，结论倒是一致：日常建站和轻量数据库负载完全够用。

带宽要分时段看。测评在三个时间点测过：早上 7 点能跑满 2.5Gbps，部分测速节点甚至冲到 10Gbps 以上；晚 8 点基本稳定在 2.5Gbps；夜里 11 点的晚高峰部分节点因运营商拥塞有所下降，但整体仍在能用的水平。中国方向实测，上海联通 5G 下行 1.7Gbps、苏州电信 5G 下行 2.5Gbps、成都移动下行 630Mbps——三网都能跑到几百 Mbps 往上，这在跨太平洋线路里不多见。

顺带一提，测评机器装的是 Debian 12，KVM 架构，BBR 拥塞控制已配置好，长距离 TCP 传输的调优不用自己动手。
